# Security Policy

## Supported versions

`0.0.x` is beta. Security and save-corruption fixes are accepted for the latest beta release.

## Reporting issues

Please open a GitHub issue for non-sensitive bugs. If a report includes private save data or other sensitive details, avoid posting the save publicly; describe the failure and provide a minimal reproduction where possible.

## Safety expectations

This tool edits local game saves. Treat every release as beta until verified in-game:

- back up saves before use
- write only to cloned saves
- verify cloned saves in Underrail before continuing a long playthrough
